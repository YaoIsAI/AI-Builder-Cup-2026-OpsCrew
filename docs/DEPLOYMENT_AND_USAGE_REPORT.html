🧠 OpsCrew 决策协同链与确定性风控

为杜绝 AI 自由发挥导致的财务合规风险，OpsCrew 构建了严格的确定性约束链条：

[ 输入原始发票与单据 ] ➔ ① 事实归一化 (FACTS Agent - Prompt 1.0.0)
│ 提取金额、币种、商户、员工编号、明细
▼
② 确定性规则库匹配 (SYN-001 ~ SYN-008, 0 Token 硬判定)
│ 绑定确定性条款集合与合规边界
▼
③ 建议方案规划 (PLANNER Agent - Prompt 1.0.1)
│ 输出：APPROVED / EVIDENCE_REQUEST / BLOCKED
▼
④ 独立盲审交叉复核 (REVIEWER Agent - Prompt 1.0.1)
│ 具备一票否决权 (Veto) 与精准引用比对
▼
[ 人机协同确认 (Human-in-the-Loop) ➔ 生成审计唯一案卷 ]

8 项确定性规则库 (Deterministic Policy SYN-001 ~ SYN-008)

规则编号 政策名称 判定逻辑 执行动作
SYN-001 金额基准阈值 单笔 $\le \$500$ 自动流转；$>\$500$ 强制人工复核 REVIEWABLE / 人工双签
SYN-002 凭证完整性 消费金额 $>\$25$ 时必须附带清晰原始票据 缺失时触发 SYN-004
SYN-003 员工身份匹配 报销人 ID 与系统授权登记账户必须完全一致 冲突直接 BLOCKED 阻断
SYN-004 凭证补交诉求 合理差旅无发票场景，下发补签承诺书与替代佐证诉求 EVIDENCE_REQUEST
SYN-005 预支款核销 存在差旅预借款时优先对冲余额，禁止重复结算 RECONCILIATION
SYN-006 公私账单拆分 剔除非公务开支与随行人员个人消费 SPLIT_CLAIM
SYN-007 币种与汇率审计 仅核准 USD 报销，异国货币须经核定基准汇率折算 USD_CONVERSION_AUDIT
SYN-008 红线违禁品类 严禁报销高档烟酒、奢侈品与娱乐场所消费 强制一票否决 BLOCKED
